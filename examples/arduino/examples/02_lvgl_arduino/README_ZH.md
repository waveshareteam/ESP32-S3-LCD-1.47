# 02_lvgl_arduino

[English](README.md)

## 功能

该示例初始化 ST7789 LCD 和 LVGL，并在界面中演示 TF 卡、无线和 RGB LED 状态。

## 硬件需求

需要 ESP32-S3-LCD-1.47 开发板和一张 TF 卡。

## 怎么运行

在 Arduino IDE 中选择 ESP32S3 Dev Module，使用 Arduino-ESP32 4.0.0 编译 `02_lvgl_arduino.ino`。

## 预期现象

LCD 显示 LVGL 控件界面，界面更新 Flash 容量和运行状态。
